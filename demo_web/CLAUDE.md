# บ้านรอด AI: กติกาสำหรับ Claude Code

อ่าน README.md ก่อนเริ่มงาน

- แก้เฉพาะไฟล์ต้นทาง (`shell.html`, `app.js`, `engine.js`, `rules.js`) ห้ามแก้ `dist/index.html` แก้เสร็จให้รัน `python3 build.py`
- ก่อนบอกว่าเสร็จ ต้องรัน `node test.js` และ `node rules.test.js` ให้ผ่านทั้งคู่ ถ้ามี jsdom ให้รัน `node smoke.test.js` ด้วย
- ตัวเลขงบทุกตัวต้องคำนวณด้วยโค้ดใน `engine.js` ห้ามให้ LLM คำนวณหรือแต่งตัวเลข เปลี่ยนสูตรต้องเพิ่มกรณีทดสอบใน `test.js`
- แก้ตัวอ่านสลิป: เพิ่มข้อความ OCR จริง (ปิดชื่อและเลขบัญชีก่อน) เป็นกรณีทดสอบใน `test.js` ก่อน แล้วค่อยแก้ `parseShop` / `parseSender` / `parseAcct`
- เพิ่มคำหรือร้านในกฎ: แก้ `RULES` ใน `rules.js` (กฎบนชนะกฎล่าง คำภาษาอังกฤษจับเป็นคำทั้งคำ) แล้วเพิ่มกรณีใน `rules.test.js`
- เลขบัญชีใช้ได้เฉพาะของผู้รับ (`parseAcct(lines, shop)`) และใช้จับคู่ร้านเองเฉพาะเมื่ออ่านชื่อไม่ได้
- ข้อมูลที่ไม่ใช่ของจริงต้องมี `source: 'sample'` เพื่อให้หน้าจอติดป้าย "ตัวอย่าง"
- ห้ามใส่กุญแจ API ในโค้ดฝั่งผู้ใช้ ห้ามสร้าง git remote หรือ push ถ้าเจ้าของงานไม่สั่ง
- ข้อความบนหน้าจอเป็นภาษาไทย สั้น บอกตรงๆ ว่าเกิดอะไรขึ้น
